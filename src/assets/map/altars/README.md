# 血月祭壇截圖 / Red Moon altar screenshots

站長自己的遊戲截圖，地圖頁點開祭壇時顯示。每個祭壇兩張：
`NN-scene.webp`（現場畫面）與 `NN-map.webp`（遊戲地圖上的位置），NN 是祭壇編號。
原圖很暗，已先調亮（自動色階＋gamma）再轉成 1280px 寬的 WebP。新增時照同樣命名，重新建置即可。

The owner's own screenshots, shown in an altar's popup on the map page: `NN-scene.webp`
(the spot in game) and `NN-map.webp` (where it is on the in-game map). Brightened, 1280 px WebP.
