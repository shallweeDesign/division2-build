# 黑暗時刻行動截圖 / Operation Dark Hours screenshots

把自己的遊戲截圖放在這裡，用項目編號命名：`01.jpg` … `06.jpg`（也可用 .png / .webp），
編號對照 `src/data/collectibles/raid-dark-hours.ts` 裡的 `n`（鑰匙和背包飾品都有編號）。
重新建置後就會出現在收集品頁；沒有檔案的項目會顯示空白框和攻略連結。

Drop your own in-game screenshots here, named by item number: `01.jpg` … `06.jpg`
(.png / .webp also work), matching `n` in `src/data/collectibles/raid-dark-hours.ts`.

請只放自己截的圖，別人的攻略或影片截圖有版權。
Only use screenshots you took yourself — other guides' images are copyrighted.
