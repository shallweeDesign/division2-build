# 破雨行動・河狸截圖 / Broken Rain beaver screenshots

把自己的遊戲截圖放在這裡，用地點編號命名：`01.jpg` … `30.jpg`（也可用 .png / .webp）。
重新建置後就會出現在收集品頁對應的地點；沒有檔案的地點會顯示空白框和攻略連結。

Drop your own in-game screenshots here, named by location number: `01.jpg` … `30.jpg`
(.png / .webp also work). They appear on the collectibles page after a rebuild.

建議：寬 1280px 左右、JPG 品質 80，每張約 150–250 KB。
請只放自己截的圖，別人的攻略或影片截圖有版權。
Only use screenshots you took yourself — other guides' images are copyrighted.
